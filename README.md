# RSVP читалка

Локальна читалка для швидкого читання методом RSVP: по одному слову в центрі екрана, червона ORP-літера на мітці (як у Spritz). Працює на Windows-ноуті, сервер слухає лише `127.0.0.1:8765`.

## Запуск
`start.bat` → відкриється браузер з бібліотекою. Закрити вікно консолі = зупинити.

## Книги
Теки зі списку `book_dirs` у `config.json` (рекурсивно) + `books/`. Формати: PDF, EPUB, FB2, MOBI, XPS, CBZ (PyMuPDF), DjVu (`djvutxt`).
Скани без текстового шару показуються з повідомленням «потрібен OCR» — OCR ще не зроблено.

## Керування
Пробіл — пуск/пауза · ← → — речення · ↑ ↓ — швидкість ±25 слів/хв · Esc — бібліотека. Прогрес і швидкість зберігаються в `localStorage` браузера для кожної книги.

## Залежності
- Python 3.13 venv: `py -3.13 -m venv venv` → `venv\Scripts\pip install pymupdf==1.27.2.3`
- DjVuLibre 3.5.29: `scoop install djvulibre`

## Рішення
- Текст дістає Python (PyMuPDF / djvutxt), браузер лише показує: pdf.js з `file://` блокує воркери, а DjVu у браузері без сервера не читається.
- `djvutxt` пропускає сторінки без тексту (418 сторінок → 414 `\f`), тому номер сторінки DjVu приблизний (`стор. ~N`), позиція в словах — точна.
- Розбиті переноси `¬\n` (DjVu) і `-\n` + мала літера склеюються; рядки-номери сторінок відкидаються.
- Таблиця ORP (довжина → індекс літери) звірена з кадрами еталонного відео (`tests/rsvp-core.test.mjs`).
- Кеш витягу — `cache/<sha1(path|size|mtime|EXTRACT_VERSION)>.json`; змінив очистку → підніми `EXTRACT_VERSION` у `server.py`.
