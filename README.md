# RSVP читалка

Локальна читалка для швидкого читання методом RSVP: по одному слову в центрі екрана, червона ORP-літера на мітці (як у Spritz). Працює на Windows-ноуті, сервер слухає лише `127.0.0.1:8765`.

## Запуск
`start.bat` → відкриється браузер з бібліотекою. Закрити вікно консолі = зупинити.

## Книги
Теки зі списку `book_dirs` у `config.json` (рекурсивно): зараз Робочий стіл, `books/`, Telegram Desktop. Список у бібліотеці фільтрується за текою і назвою. Формати: PDF, EPUB, FB2, MOBI, XPS, CBZ (PyMuPDF), DjVu (`djvutxt`).

## OCR сканів
Книга без текстового шару (скан PDF / DjVu) показує кнопку «Розпізнати текст (OCR)». Розпізнавання йде у фоні з прогресом; результат кешується, книга далі відкривається як звичайна.
- Tesseract 5, мови `rus+ukr+eng`, 300 dpi, паралельно `cpu_count/2` процесів (до 16).
- Замір 2026-10-17: 0.62 с/стор. на 16 процесах, DjVu на 472 стор. ≈ 5 хв.
- Кеш посторінковий: `cache/ocr/<sha1(path|size|mtime)>/NNNN.txt`. Перерваний OCR продовжується з місця зупинки; збійна сторінка лишається порожньою і повторюється на наступному запуску.
- Одночасно розпізнається одна книга.

## Керування
Кнопки: ⏪ стор · ⏮ реч · ◀ сл · ▶/⏸ · сл ▶ · реч ⏭ · стор ⏩; швидкість − [поле] +; розмір слова A− [px] A+ (24–120 px).
Клавіші: Пробіл — пуск/пауза · ← → — речення · Shift+← → — слово · PageUp/PageDown — сторінка · ↑ ↓ — швидкість ±25 слів/хв · + − — розмір · Esc — бібліотека.
Прогрес і швидкість зберігаються в `localStorage` браузера для кожної книги, розмір шрифту — один на всі книги.

## Залежності
- Python 3.13 venv: `py -3.13 -m venv venv` → `venv\Scripts\pip install pymupdf==1.27.2.3`
- DjVuLibre 3.5.29: `scoop install djvulibre`
- Tesseract-OCR 5.4 (UB Mannheim build) у `PATH` або в `C:\Program Files\Tesseract-OCR\`.
- Мовні моделі в `tessdata/` (не в git): `eng`, `rus`, `ukr` `.traineddata` з https://github.com/tesseract-ocr/tessdata (гілка `main`).

## Рішення
- Текст дістає Python (PyMuPDF / djvutxt), браузер лише показує: pdf.js з `file://` блокує воркери, а DjVu у браузері без сервера не читається.
- `djvutxt` пропускає сторінки без тексту (418 сторінок → 414 `\f`), тому номер сторінки DjVu приблизний (`стор. ~N`), позиція в словах — точна.
- Розбиті переноси `¬\n` (DjVu) і `-\n` + мала літера склеюються; рядки-номери сторінок відкидаються.
- Таблиця ORP (довжина → індекс літери) звірена з кадрами еталонного відео (`tests/rsvp-core.test.mjs`).
- Кеш витягу — `cache/<sha1(path|size|mtime|EXTRACT_VERSION)>.json`; змінив очистку → підніми `EXTRACT_VERSION` у `server.py`. Сирий OCR-текст від `EXTRACT_VERSION` не залежить, тому підняття версії не запускає OCR заново.
- OCR = Tesseract, а не Windows.Media.Ocr: у вбудованому OCR Windows немає української.
- `POST /api/ocr/<id>` відхиляє запит із чужим `Origin`: сторінка іншого сайту не запустить важку роботу на ноуті.
